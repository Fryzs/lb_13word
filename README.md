# lb_13word — експорт таблиці у Word

Лабораторна робота №13 на Windows Forms (.NET), що працює з Microsoft Word через Office Interop.

## Що вміє

- **Експорт у Word** — створює новий документ із жирним заголовком по центру (дані з полів форми) і таблицею з рамками, у яку переносяться всі рядки з `DataGridView`.
- **Імпорт із Word** — відкриває раніше збережений документ, зчитує заголовок назад у поля форми, а таблицю — у `DataGridView`.

## Запуск

Потрібен встановлений Microsoft Word. Відкрийте `lb_13.sln` у Visual Studio і натисніть F5.
